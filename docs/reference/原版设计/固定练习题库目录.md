# 固定章节练习题库

当前题库共 5 门课、25 章、50 个知识点、500 道题。每章固定 20 题，每个知识点 10 题。

## 高等数学

1. 极限与连续：基本极限、连续性；20 题。
2. 导数与微分：幂函数求导、导数的应用；20 题。
3. 不定积分：基本积分公式、积分性质；20 题。
4. 定积分：定积分计算、定积分的性质与应用；20 题。
5. 多元函数基础：偏导数、二重积分基础；20 题。

## 数据库系统原理

1. 关系模型与完整性：关系模型、键与完整性；20 题。
2. SQL 数据查询：基础查询、分组与聚合；20 题。
3. SQL 更新与约束：数据修改、表结构与约束；20 题。
4. 函数依赖与规范化：函数依赖、范式与冗余；20 题。
5. 事务与并发控制：事务性质、并发与锁；20 题。

## 单片机

1. 数制与存储：二进制换算、位与字节；20 题。
2. GPIO 输入输出：输入与电平、输出与驱动；20 题。
3. 定时器与中断：定时与计数、中断基础；20 题。
4. 串行通信：UART 通信、常用串行总线；20 题。
5. 嵌入式程序基础：C 语言基础、程序流程与资源；20 题。

## 数据结构

1. 线性表：顺序表、链表；20 题。
2. 栈与队列：栈、队列；20 题。
3. 树与二叉树：二叉树基础、二叉树遍历；20 题。
4. 图：图的基本概念、图的遍历；20 题。
5. 查找与排序：查找、排序；20 题。

## 计算机网络

1. 网络体系结构：分层结构、协议基础；20 题。
2. 数据链路层：以太网与MAC、交换机转发；20 题。
3. 网络层：IPv4 地址、路由基础；20 题。
4. 传输层：TCP、UDP；20 题。
5. 应用层：HTTP、DNS；20 题。
