版本：1.1  
日期：2026年10月19日  
依据：需求文档 1.5、数据库设计 1.2  
阶段：页面与接口设计，尚未编写业务代码

## 1 页面组织

采用多个 HTML 页面，共享 CSS、JavaScript 和请求封装。浏览器从 Nginx 获取页面，通过同一入口的 /api/ 访问 Spring Boot。前端不使用 Vue、React 或构建工具。

学生导航为“学习首页、开始练习、练习记录、错题本、薄弱项、账号设置”；管理员导航为“整体统计、学生管理、账号设置”。管理员从学生列表进入学生详情，再查看其练习和错题。管理员没有题库维护或开始练习入口。

所有页面采用中文，统一页头、侧栏、内容区域和提示样式。学生个人信息与管理员学生详情可以共享展示组件，但后端使用不同权限接口。

## 2 关键交互

### 2.1 登录与改密

登录成功保存 JWT 至 sessionStorage，直接按角色进入首页，不强制修改密码。自愿修改密码后清除令牌并重新登录。

密码修改校验原密码、新密码和确认密码。确认密码只在前端比较，不传给后端。后端独立校验新密码至少 6 位、与默认密码不同。管理员重置学生密码时明确提示重置为 123456 且将使旧登录失效。

### 2.2 练习与结果

切换课程时清空章节、知识点选择，切换章节时清空知识点。课程必选，章节和知识点可不选；已选知识点须属于已选课程，若同时指定章节则须属于该章节。

默认题量 5，可输入 1 至 50 的整数，以满足小型示例题库。实际数量不足时，创建成功后提示实际题量。普通练习混合抽取三种题型，不增加题型配额配置。

开始练习时后端创建练习及固定排列，前端保存当前页面中的选择。上一题、下一题或点击答题卡不改变排列。页面刷新、离开、登录失效可能丢失未提交答案；答题页给予清楚提示，离开时尽可能提示确认，不承诺浏览器一定弹出提示。

提交前显示未答题量；确认后暂时禁用提交按钮。成功进入结果页；网络异常保留当前页面答案并允许重试。同一练习重复提交返回已保存的结果。

结果页保留本次显示顺序。未作答显示“未作答”，不能用空答案或空数组显示替代文字。单选、多选的正确答案按显示字母呈现，判断使用“正确、错误”。

### 2.3 错题与薄弱项

错题本按题目去重，显示题干摘要、历史错误次数、最近作答是否正确。查看错题打开最近一次错误练习的详情，并定位该题，以还原当时选项。

错题重练需先选课程，支持勾选该课程的题目，最多 50 道。只允许提交本人曾经答错且属于选定课程的题目 ID，由后端复核，不允许用其他题目冒充错题。

薄弱项表展示知识点、不同题目数、正确题数、正确率和等级。样本不足显示练习不足。复习按钮将课程、章节和知识点带入普通练习选择页，不自动增加额外推荐算法。

### 2.4 管理员查看

整体统计默认先展示课程概览，选择某课程后显示知识点共性薄弱项及该课程学生统计表。学生表按学号排列，支持分页，不按分数排名。

学生详情页切换课程时更新统计、趋势、知识点、练习列表和错题筛选。管理员可查看结果与解析，但不展示作答或修改成绩按钮。

## 3 接口通用约定

- 所有业务接口以 /api 开头，使用 JSON，Content-Type 为 application/json。
- 登录之外均要求 Authorization: Bearer 令牌；默认密码账号与其他账号使用相同的角色权限。
- 返回格式为 code、msg、data；code = 1 表示成功，0 表示失败。
- 分页 data 为 total、rows；page 默认 1，pageSize 默认 10，最大 50。
- ID 全部使用字符串。数量为整数，布尔值使用 JSON true/false，时间使用 ISO 本地时间字符串，如 2026-10-19T18:55:11.657，时区为 Asia/Shanghai；前端格式化后展示。
- 比例字段 accuracy 为 0 至 100 的数值，显示保留一位小数；无分母时为 null。掌握等级根据未舍入比例计算。
- 401 表示登录失效，403 表示角色无权限，404 表示资源不存在，400 表示参数错误，409 表示账号重复等冲突，500 返回通用错误提示。
- 学生访问其他学生资源统一返回 404，避免泄露资源是否存在。管理员不得调用学生作答接口。
- 前端以 textContent 等文本方式插入题干、姓名和解析，不将这些内容当作 HTML 执行。

统一响应示例：

```json
{
  "code": 1,
  "msg": "success",
  "data": {"total": 0, "rows": []}
}
```

其中 total 表示实际总条数，以上为空列表的响应示例。

## 4 接口清单

### 4.1 身份与课程查询

| 方法 | 路径 | 权限 | 输入与输出 |
| --- | --- | --- | --- |
| POST | /api/auth/login | 公开 | username、password；返回 token 和当前用户基本信息 |
| GET | /api/auth/me | 已登录 | 返回 id、username、realName、role、mustChangePassword |
| POST | /api/auth/logout | 已登录 | 令牌版本递增，返回成功 |
| PUT | /api/auth/password | 已登录 | oldPassword、newPassword；成功后旧令牌失效 |
| GET | /api/courses | 已登录 | 课程 id、name、description、questionCount |
| GET | /api/courses/{courseId}/chapters | 已登录 | 章节列表与题量 |
| GET | /api/courses/{courseId}/knowledge-points | 已登录 | 可选 chapterId；返回知识点及其题量 |

课程查询只提供必要目录信息，不返回原始标准答案，不提供课程或题目写入接口。

### 4.2 学生练习

| 方法 | 路径 | 输入 | 输出 |
| --- | --- | --- | --- |
| POST | /api/student/practices | courseId、可选 chapterId、knowledgeId、count | practiceId、requestedCount、actualCount |
| POST | /api/student/practices/from-wrong | courseId、questionIds | 新 practiceId、actualCount |
| GET | /api/student/practices/{practiceId}/questions | 路径 ID | 本次题目及按排列生成的选项，不含答案解析 |
| POST | /api/student/practices/{practiceId}/submit | answers 数组 | practiceId、questionCount、correctCount、accuracy |
| GET | /api/student/practices | 可选 courseId，分页 | 本人的已提交练习列表 |
| GET | /api/student/practices/{practiceId}/result | 路径 ID | 本人成绩与逐题详情；未提交返回 409 |

以上接口均限制学生身份。题目查询接口用于开始练习后首次加载；第一版不提供恢复已选答案。已提交练习的 questions 请求引导访问结果，不继续提供答题。

创建普通练习示例：

```json
{"courseId":"1","chapterId":"2","knowledgeId":"3","count":5}
```

题目响应中的一条记录：

```json
{
  "itemId":"101",
  "orderNo":1,
  "questionType":"SINGLE",
  "stem":"以下哪一项属于关系数据库语言？",
  "options":[
    {"label":"A","text":"HTML"},
    {"label":"B","text":"SQL"},
    {"label":"C","text":"CSS"},
    {"label":"D","text":"XML"}
  ]
}
```

响应不暴露原始映射或正确答案。前端只认当前显示 label。判断题 options 为 A 正确、B 错误。

提交示例：

```json
{
  "answers":[
    {"itemId":"101","selectedLabels":["B"]},
    {"itemId":"102","selectedLabels":["D","A"]},
    {"itemId":"103","selectedLabels":[]}
  ]
}
```

后端规范化集合顺序，但拒绝重复选项、无效字母、重复 itemId 及其他练习明细。缺失的本次题目视为未作答。正确答案不接受前端传入。

结果详情每题返回 itemId、questionId、orderNo、questionType、stem、options、selectedLabels、correctLabels、isCorrect、explanation；选项和字母均使用本次排列。判断题前端将 A/B 转成中文呈现。

### 4.3 学生错题与分析

| 方法 | 路径 | 输入 | 输出 |
| --- | --- | --- | --- |
| GET | /api/student/wrong-questions | 可选 courseId、knowledgeId，分页 | questionId、stem、wrongCount、latestCorrect、lastWrongPracticeId、lastWrongItemId |
| GET | /api/student/summary | 无 | 按课程返回累计练习次数、题量、正确次数、正确率 |
| GET | /api/student/knowledge-analysis | courseId | 知识点题量、正确率、等级及复习次序 |
| GET | /api/student/trend | courseId | 最近 20 次已提交练习，按提交顺序展示时间、题数及正确率 |

个人分析等级字段 level 为 NO_DATA、INSUFFICIENT、WEAK、REVIEW、GOOD，对应暂无记录、练习不足、优先复习、需要巩固、掌握较好。展示名称由前端固定映射。

### 4.4 管理员学生账号

| 方法 | 路径 | 输入 | 输出 |
| --- | --- | --- | --- |
| GET | /api/admin/students | 可选 keyword、enabled，分页 | 学号、姓名、状态、创建时间 |
| POST | /api/admin/students | username、realName | 创建的账号信息，不返回密码哈希 |
| PUT | /api/admin/students/{studentId}/status | enabled 布尔值 | 更新成功，停用使旧令牌失效 |
| POST | /api/admin/students/{studentId}/reset-password | 无 | 重置为 123456，可直接登录 |

创建接口不接受 role、passwordHash、tokenVersion 等字段。密码由后端按默认规则处理。状态、重置接口仅允许目标为 STUDENT，不能借此修改管理员。

### 4.5 管理员统计和学生详情

| 方法 | 路径 | 输入 | 输出 |
| --- | --- | --- | --- |
| GET | /api/admin/summary | 无 | 学生总数、启用数及各课程累计统计、参与人数 |
| GET | /api/admin/knowledge-analysis | courseId | 各知识点参与人数、有效组合数、正确率、等级 |

| GET | /api/admin/students/{studentId} | 路径 ID | 学生基本信息 |
| GET | /api/admin/students/{studentId}/summary | 无 | 该学生各课程累计统计 |
| GET | /api/admin/students/{studentId}/knowledge-analysis | courseId | 个人知识点分析 |
| GET | /api/admin/students/{studentId}/trend | courseId | 最近 20 次练习趋势 |
| GET | /api/admin/students/{studentId}/practices | 可选 courseId，分页 | 已提交练习列表 |

## 5 服务端组织

| Controller | Service | Mapper | 职责 |
| --- | --- | --- | --- |
| AuthController | AuthService | UserMapper | 登录、改密、退出和当前用户 |
| CourseController | CourseService | CourseMapper | 查询课程、章节、知识点 |
| PracticeController | PracticeService | PracticeMapper、QuestionMapper | 抽题、排列、提交及结果 |
| LearningController | LearningService | LearningMapper | 错题、个人统计、知识点和趋势 |
| AdminStudentController | StudentService | UserMapper | 学生账号管理 |
| AdminReportController | ReportService、LearningService | ReportMapper、LearningMapper | 整体统计及学生详情 |

统一登录拦截器验证 JWT、账号状态、登录版本、角色。Service 对具体练习归属再次检查。方法参数使用请求 DTO，查询结果使用响应 DTO，不直接序列化含 password_hash 或 correct_answer 的数据库实体。

## 7 接口与页面验收

1. 学生账号只能通过本人接口取得数据；修改 URL、练习 ID 或提交明细不能访问他人内容。
2. 管理员导航无题库维护，服务端无课程和题目写入接口。
3. 学生使用初始或重置后的密码可以直接访问学习功能，不跳转强制改密页面。
4. 抽题和评分使用后端保存的排列，刷新题目请求不生成新排列。
5. 正确答案与解析仅在提交后的受保护结果接口返回。
6. 单选只选一项，多选可选多项，判断顺序固定；未作答提交有提示。
7. 错题重练按同一题统计，最近答对保留曾错记录。
8. 题量、样本量、累计与近期统计口径在页面中清楚展示。
9. 停用、重置密码和退出后旧 JWT 不能继续使用。
10. 无数据、题目不足、网络失败和重复提交均有明确页面反馈。

## 9 固定章节练习补充

student/practice.html 默认展示固定章节练习，按课程列出五章，每套二十题，显示完成次数、最近成绩与结果入口。自主随机练习放在相邻标签页，保留范围及题量设置；从知识点复习入口进入时默认打开自主随机练习。

新增 GET /api/student/practices/chapter-sets?courseId=...，返回 chapterId、chapterName、chapterNo、questionCount、completedAttempts、latestPracticeId、latestCorrectCount、latestAccuracy、lastSubmittedAt。

新增 POST /api/student/practices/chapters/{chapterId}，创建该章节固定全卷。所有学生的题目和顺序相同，选择题选项各自随机。管理员不能调用学生开始练习接口，旧章节不能作为新固定练习打开。

题目与结果响应增加 practiceName，历史记录增加 chapterName，sourceType 可为 CHAPTER。归档练习不出现在当前历史、错题和统计中，旧记录仍保存在数据库。


## 10 管理员交互同步

新增 admin/courses.html 课程概览与 admin/practices.html 全部练习记录。管理员首页四个统计卡片、课程卡片及学生详情统计卡片均使用原生超链接，分别进入对应列表或分析内容。学生详情支持 tab=overview、history、wrong 与 courseId 参数，保证卡片跳转时保留学生和课程范围。

新增 GET /api/admin/practices，支持 courseId、studentId、page、pageSize；只返回未归档且已提交的练习，包含学生姓名学号、课程、章节及成绩。接口仅限管理员，不改变学生原有的个人查询范围。全部管理员分页列表使用统一的每页条数输入。
